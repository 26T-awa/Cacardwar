# 牌牌大作战数据包

<center> By _26T </center>

## 简介

**牌牌大作战**是一个MC Java原版数据包。在牌牌大作战，你可以使用基于MC原版物品的**卡牌**，利用原版以及新颖的**合成配方**，**进攻、防守、回复甚至召唤**，与好友一起进行激情而愉快的决斗，**取得成就、完成挑战**。这是一个小游戏数据包。

> **Description** in English:  
> **CacardWar** is a Minecraft Datapack that using **cards** based on original Minecraft items to fight with your friends through various **original or customed recipes, achieve amazing challenges and so on**. Treat it as a mini-game running on Minecraft Java Edition.

## 安装说明

### 加载数据包

- 新建存档，找到世界文件夹，将**cacardwar datapack**放进存档的**datapacks**(.../saves/<存档名称>/datapacks/)文件夹里即可。
   > 注：在不同的版本下"cacardwar datapack"可能是"cacardwar" 或 "cacardwar datapack vx.x"

- 新建存档界面，在“**更多**”里找到“**数据包**”，点击“打开包文件夹”将**cacardwar**放进即可。

- 在已有的存档里找到世界文件夹，同1，后在游戏中输入`/datapack enable "file/cacardwar"`，最后输入`/reload`或重进游戏即可。

### 构建场地

获得**结构方块**(`/give @s structure_block`)，在“**加载模式**”下输入"cacardwar:start"（v3.3+：或"start"或"c:start"）后，将右侧“**严格放置**”和“**包括实体**”设为“**开**”，最后**两次点击**“**加载**”即可。

### 因物品展示框被破坏而影响正常游戏体验的解决方法

> **在cacardwar v4.1~v4.3可直接点击“仅重置物品展示框”悬挂式告示牌**  
> **在cacardwar v5.1+可直接点击“仅恢复物品展示框”悬挂式竹告示牌**  

1. （**推荐**）：将场地内所有的实体（包括门外的鹦鹉、盔甲架和存放更新日志的物品展示框）清除，建议用指令`/kill @e[type=!player,distance=..5]`，然后回到已有的结构方块点击一次加载即可。

2. （**不推荐**）：按荧光物品展示框左侧的物品展示框为“头”，备用物品展示框为“尾”,依次为1 2 3 ... 9 0的顺序，使用指令`/tag <UUID> add cacard.<team>X` ，然后再对台上的9个物品展示框使用指令`/tag <UUID> add cacard.<team>`即可。  

    > 注：\<UUID>指对着物品展示框补全命令时的一串字符；\<team>指队伍，蓝方为blue，红方为red；X指数字1 2 3 ... 9 0

> 详细计算公式
<a id="R1"></a>

#### R1：有效合成/使用

**触发**：进行了一次有效合成/使用（任意配方）

`reward = 0.3 × (1 + 消耗卡牌数 × 0.01 - 无关槽位卡牌数 × 0.02)`

| 参数 | 说明 |
| :--- | :--- |
| 消耗卡牌数 | 本次合成/使用理论消耗的卡牌张数 |
| 无关槽位卡牌数 | 合成时位于其它槽位中被浪费的卡牌数 |

<a id="R2"></a>

#### R2：合成护盾

**触发**：合成的是护盾

`reward = 0.08 × (1 + 原护盾重复修正)`

| 修正项 | 条件 | 值 |
| :--- | :--- | :--- |
| 原护盾重复修正 | 未重复 | 0 |
| 原护盾重复修正 | 重复 | -10 |

<a id="R3"></a>

#### R3：合成召唤物

**触发**：合成的是召唤物

`reward = 0.2 × (1 + 僵尸加成 + 商人加成 + 超级僵尸加成 + 稻草人加成 + 溢出补偿修正)`

| 召唤物类型/修正 | 说明 | 值 |
| :--- | :--- | :--- |
| 僵尸 | 召唤僵尸 | +0.05 |
| 商人 | 召唤商人 | +0.02 |
| 超级僵尸 | 召唤超级僵尸 | +0.20 |
| 稻草人 | 召唤稻草人 | +0.01 |
| 溢出补偿修正 | 未溢出 | 0 |
| 溢出补偿修正 | 溢出，但有同类型召唤物触发补偿 | -0.1 |
| 溢出补偿修正 | 溢出，且无同类型召唤物触发补偿 | -10 |

<a id="R4"></a>

#### R4：合成金苹果

**触发**：合成的是金苹果

`reward = 0.3 × (1 + 血量溢出修正 + 饥饿抵消修正 + 恢复被禁用的槽位修正)`

| 修正项 | 条件 | 值 |
| :--- | :--- | :--- |
| 血量溢出修正 | 加后生命值溢出（超过上限） | -0.1 |
| 血量溢出修正 | 加后生命值未溢出 | +0.1 |
| 饥饿抵消修正 | 抵消了饥饿效果 | +0.2 |
| 饥饿抵消修正 | 未抵消饥饿效果 | 0 |
| 恢复被禁用的槽位修正 | 恢复了N个被禁用的槽位 | +N*0.05 |

<a id="R5"></a>

#### R5：合成金头颅

**触发**：合成的是金头颅

`reward = 0.05`

固定奖励，无倍率。

<a id="R6"></a>

#### R6：合成镐

**触发**：合成的是镐

`reward = 0.04 × (1 + 钻石镐修正 + 偷取加成修正)`

| 修正项 | 条件 | 值 |
| :--- | :--- | :--- |
| 钻石镐修正 | 合成的是钻石镐 | +1.0 |
| 钻石镐修正 | 合成的是铁镐 | 0 |
| 偷取加成修正 | 成功偷取 | +0.02 |
| 偷取加成修正 | 偷取空槽位 | -10 |

<a id="R7"></a>

#### R7：获得饥饿效果

**触发**：在本回合获得了饥饿效果

`reward = -0.2 × (1 - 获得途径修正)`

| 修正项 | 条件 | 值 |
| :--- | :--- | :--- |
| 获得途径修正 | 由召唤超级僵尸获得 | 1 |
| 获得途径修正 | 由使用腐肉获得 | 0 |

<a id="R8"></a>

#### R8：获得乌鸦的赐福效果

**触发**：在本回合获得了乌鸦的赐福效果（正面增益）

`reward = 0.1`

固定奖励，无倍率。

<a id="R9"></a>

#### R9：造成攻击

**触发**：本回合造成了攻击伤害

`reward = 0.1 × (1 + 伤害 × 0.5 + 斩杀线10修正 + 斩杀线5修正)`

| 参数/修正项 | 条件 | 值 |
| :--- | :--- | :--- |
| 伤害 | 造成伤害量N | N |
| 斩杀线10修正 | 最终对手生命值 < 10 | +0.2 |
| 斩杀线5修正 | 最终对手生命值 < 5 | +0.3 |

<a id="R10"></a>

#### R10：回复生命值

**触发**：本回合回复了生命值

`reward = 0.1 × (1 + 回复量 × 0.5 + 生命值12修正 + 生命值16修正)`

| 参数/修正项 | 条件 | 值 |
| :--- | :--- | :--- |
| 回复量 | 回复量N | N |
| 生命值12修正 | 最终生命值 > 12 | +0.2 |
| 生命值16修正 | 最终生命值 > 16 | +0.3 |

<a id="R11"></a>

#### R11：回合结束，剩余卡牌

**触发**：本回合结束时，手牌仍有剩余卡牌

`reward = -0.05 × (1 + 剩余卡牌数规则)`

| 剩余卡牌数 | 倍率 | 最终惩罚 |
| :--- | :--- | :--- |
| 1~3 张 | x1 | N |
| >4 张 | x0.8 | N*0.8 |

<a id="R12"></a>

#### R12：清空有卡牌的卡槽

**触发**：本回合内主动清空了一个原本有卡牌的卡槽，备用槽除外

`reward = -0.3`

<a id="R13"></a>

#### R13：行动导致胜利

**触发**：执行此行动时，取得了对局胜利

`reward = 2.0 × (1 + 生命值10修正 + 生命值16修正 + 生命值20修正)`

| 修正项 | 条件 | 值 |
| :--- | :--- | :--- |
| 生命值10修正 | 最终生命值 > 10 | +0.08 |
| 生命值16修正 | 最终生命值 > 16 | +0.12 |
| 生命值20修正 | 最终生命值 = 20 | +0.30 |

<a id="R14"></a>

#### R14：本回合失败

**触发**：本回合结束时，对局失败（例如跳过回合时被对方召唤物击败）

`reward = -1.0 × (1 + 对手生命值4修正 + 对手生命值10修正 + 对手生命值20修正)`

| 修正项 | 条件 | 值 |
| :--- | :--- | :--- |
| 对手生命值4修正 | 对方最终生命值1~4（非常可惜） | -0.12 |
| 对手生命值10修正 | 对方最终生命值1~10（可惜） | -0.08 |
| 对手生命值20修正 | 对方最终生命值20（被完败） | 0.5 |
